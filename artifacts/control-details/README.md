# 控件细节统一

本轮保留原有页面结构，在深浅色支持之上统一控件几何和状态。未恢复之前撤回的下载页重排、速度图或阶段组件。

- 页签、外观选择和菜单：4px 内边距、2px 项间距、8px 内圆角、12px 外圆角。
- 页签及紧凑按钮：32px；常规按钮、输入框、下拉触发器和菜单项：36px。水平内边距统一为 12px。
- 选中页签使用内描边，避免描边挤占留白；焦点使用 2px 轮廓，分组内使用内侧轮廓。
- 统一禁用透明度、按下反馈和鼠标悬停状态。历史菜单根据实际高度定位。

## 验证

- `npm run build:app`：通过。
- `node scripts/appearance-regression.cjs`、`node scripts/download-queue-regression.cjs`：通过。
- `git diff --check`：通过。
- 内部浏览器加载真实 Vue 源码，使用已有 Tauri IPC 模拟夹具；没有启动真实下载。
- 在 720、960、1180px 视口检查相关控件，未观察到横向溢出；深浅色页签和外观选择的四边留白均实测 4px。
- 下拉及历史菜单实测：4px 留白、2px 项间距、36px 行高；方向键可切换，Esc 关闭后焦点返回触发按钮。
- 队列 More 菜单采用相同尺寸；高对比度下页签选择及焦点可见；浏览器控制台无错误。

`before/` 保存本轮修改前的源文件并已核对哈希；`measurements.json` 保存浏览器测量结果。PNG 为最终渲染截图。
