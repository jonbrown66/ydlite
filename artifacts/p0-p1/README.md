# 0.2.0 下载功能与块状 Tab 验证

本轮实现文件命名预设、中文标题、按媒体和格式区分文件、跳过/编号/确认覆盖、详细格式与音轨选择、兼容/质量策略、错误分类与恢复入口。输入导航改为同一底座内的块状 Tab，保留方向键、Home/End、输入和解析结果。

## 已执行的验证

- 四组 Node 回归通过：下载状态、持久化队列、历史/偏好兼容、文件/音轨选项与覆盖确认。详细格式收起后仍显示已经选中的格式。
- Rust 44 项本地检查通过，包括真实 yt-dlp 的缓存复用、失效地址恢复、取消、路径与终态，以及可播放媒体的跳过、编号、确认覆盖、MP3 转换和指定格式失效。
- 新增的独立音轨回归另外通过：视频与 440/880 Hz 音轨分别生成，实际选择 zh 音轨后解码测量频率确认使用 880 Hz；兼容/质量合并分别生成 MP4/MKV。
- 公开 Bilibili `BV1nx411u79K` 经过实际应用 Rust 解析/下载链路，Best、720p、MP3 均成功；FFprobe 确认可播放，输出分别为 9,135,704、9,135,704、1,612,730 字节。下载未使用账号或 Cookie。
- Blender 官方公开媒体成功解析；YouTube 样例触发登录/机器人校验。第一个 Bilibili 样例的部分视频 CDN TLS EOF、音轨成功，替换为 yt-dlp 自带的短视频样例后完成实站验收。不能据此保证所有站点或 CDN 可用。
- 内置浏览器实际操作覆盖详细编码/帧率、音轨语言、覆盖前确认、拒绝确认、批量去重、取消和暂停、重载恢复及默认命名持久化。下载 IPC 为测试模拟，不等同于原生窗口验收。EgoLite 被用户接管后按要求停止，用户随后指定内置浏览器。
- 应用窗口宽度 720/800/900/1180px 检查无文档横向溢出；720px 设置面板无内部横向溢出。官网生产预览 1180/390px 检查通过，新图片已加载，下载链接均指向 0.2.0。
- 官网 EXE/MSI 实际 HTTP 响应为 200，响应内容 SHA256 与本地构建文件一致。
- 应用/官网构建、Rust 格式检查、Git 差异检查通过。安装包哈希见 installers.json。
- NSIS 0.1.0 首次安装及升级到 0.2.0 在项目内专用目录实际执行，退出码 0，版本为 0.2.0，测试输出文件 SHA256 不变。测试安装已卸载，未选择删除应用数据，输出哨兵文件保留。
- MSI 行政解包成功，提取程序版本为 0.2.0；这不是 MSI 安装行为验证。

## 修复与验证边界

真实覆盖回归曾捕获编号副本优先于原文件的问题，现已修复并通过实际文件内容对比。通用媒体 ID 另按来源区分，避免不同网站同名直链相互识别为同一文件。重命名文件中的百分号按字面处理。

默认沙箱曾拒绝临时文件替换、无法访问打包工具源，及阻断本机测试服务访问；通过获批的本机验证执行后相应检查通过。测试代理重启造成的一条开发 WebSocket 告警不代表生产应用运行错误。
